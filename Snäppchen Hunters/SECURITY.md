# Security policy

Please report suspected security vulnerabilities privately. Do not open a public issue for a vulnerability that could expose user data, CloudKit sharing links, or app signing material.

Use GitHub's **Report a vulnerability** feature on the repository's Security tab if it is enabled. Include a clear description, affected version or commit, reproduction steps, and any suggested mitigation. The maintainer will acknowledge valid reports and coordinate a fix before public disclosure.

If private reporting is not yet enabled, the repository owner should enable it in GitHub repository settings before the first public release.
